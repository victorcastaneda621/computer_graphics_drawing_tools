# Computer Graphics Drawing Tools

A collection of three interactive Python tools for exploring line algorithms and 2D shapes, fractal geometry, and L-Systems.
Each tool features a dedicated GUI and is self-contained within one of the following folders: `lines_shapes`, `fractals` and `l_systems`. Any of them can be launched via the "main.py" file located inside its folder. For example, in order to run the L-System tool from the root directory of the repository, the following command will be used:
```bash
python l_systems/main.py
```
After that, the GUI should apear onscreen. 

Similarly, to run the other two tools from the root directory of the repository:
```bash
python fractals/main.py
python lines_shapes/main.py
```

Each tool is independent from each other, even if they are closely related in UI style and implementation.

[!NOTE]
So far, the project has been tested on the Windows 10 OS.

## `lines_shapes`: Line Drawing and 2D Transformations

An interactive canvas for drawing lines using several algorithms, with support for 2D geometric transformations applied to the full drawing.

**Drawing lines**

Each pixel on the canvas maps to an 8×8 block of real screen pixels, making points more visible. You can click on two points on the canvas, or type canvas coordinates in the toolbar to draw a line (combining both approaches for the same line might be problematic). Four algorithms are available, and you are able observe exactly which pixels each one activates:

- **Slope-Intercept** - straightforward y = mx + b approach, adapted per quadrant
- **DDA** (Digital Differential Analyzer) - floating-point incremental method, works in any direction natively
- **Bresenham (float)** - classic error-based algorithm using floating-point arithmetic
- **Bresenham (integer)** - same logic with integer-only arithmetic, the most efficient of the four

Lines can be rendered as **solid**, **dotted**, or **dashed**, and drawn in any color.

**2D Transformations**

Once lines are on the canvas, the whole shape they form can be transformed via homogeneous coordinate matrices:

- **Translation** - shift by the vector (x, y).
- **Rotation** - by any angle, clockwise or counter-clockwise.
- **Scaling** - independently on x and y axes.
- **Shearing** - on x, y, or both.
- **Reflection** - across the X axis, Y axis, the origin, or any arbitrary line.

Transformations are tracked in a history and can be undone one step at a time. Axes and a coordinate grid can be toggled on/off for reference.

A short Pong-inspired animation that uses the transformation system to play back a frame-by-frame sequence is also included.

## `fractals`: Fractal Generation

An interactive canvas that allows the user to generate fractals through three distinct approaches, selectable from the toolbar.

**Recursive fractals**

Fractals built by repeatedly subdividing a shape. The number of iterations is configurable, and an animated mode lets you watch the structure grow step by step:

- **Sierpiński Triangle** - triangle subdivided recursively into smaller triangles.
- **Koch Curve** - line segment recursively replaced by four shorter ones forming a peak.
- **Koch Snowflake** - three Koch curves joined into a closed snowflake shape.
- **Cantor Set** - horizontal lines recursively split by removing their middle third.

**Iterated Function Systems (IFS)**

Fractals generated by repeatedly applying a set of affine transformations chosen randomly by probability, producing a point cloud that converges to a self-similar shape. Includes: Sierpiński Triangle, Koch Curve, Cantor Set, Barnsley Fern, Christmas Tree, and several abstract shapes (Blocks, Cloud, Leaf, Noisy, Chaos).

**Complex number fractals**

Point-by-point computation over a 2D grid of complex numbers, colored by how quickly each point escapes to infinity. Four color palettes are available (grayscale, orange, green-blue, green-pink):

- **Julia Set** - obtained from a complex constant *c*, configurable via the toolbar.
- **Mandelbrot Set** - the classic set that acts as a map of Julia sets.

Rendered fractals can be exported as PNG files. The `exported` subfolder already contains some examples.

## `l_systems`: L-System Generator

An interactive tool for defining and drawing [Lindenmayer systems](https://en.wikipedia.org/wiki/L-system): string rewriting grammars that produce complex geometric structures from simple rules, rendered via turtle graphics.

Users can define a system in three steps using the toolbar:

1. **Variables** - symbols that get rewritten each iteration (e.g. `F` for "move forward")
2. **Constants** - symbols that are interpreted as drawing commands but never rewritten (e.g. `+` for "turn left")
3. **Initial state** - the starting string (e.g. `F-F-F-F`)
4. **Rules** - rewriting rules applied to variables each iteration (e.g. `F → F+F-F-F+F`)

Each symbol maps to a turtle action: move forward, turn by 22.5°/60°/90°, save/restore position (for branching), change color, or do nothing.

The canvas supports **zoom** (scroll wheel) and **pan** (arrow keys). Results can be exported as SVG. The `exported` subfolder already contains examples.

**Presets**

Twelve built-in presets are included to get started:

- **Geometric:** Koch Curve, Square Pattern, Hexagonal Gosper
- **Triangles:** Sierpiński Triangle
- **Curves:** Dragon Curve
- **Plants:** Branch, Dense Tree, Coral, Dense Coral, Windy Tree
- **Colored:** Colored Branch (brown trunk, green leaves), Colored Square Pattern

These presets input the necessary values but don't automatically start the drawing process, so they are useful to get acquainted with L-systems.
